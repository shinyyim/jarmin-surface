# Explorations

The six visual directions are working pages, not mockups, so they live where they are served:
[`03-build/public/explorations/`](../../03-build/public/explorations/).

Open `explorations/` on the deploy (or run the build and visit `/explorations/README.html`) for
the gallery: four structures as wireframes, six looks as live thumbnails, each with what it was
good at and what broke it.

| | Direction | Why not |
|---|---|---|
| Structure | Inbox | The conversation has nowhere to live; the detail pane becomes a second app |
| | Chat-first | Thirty-one items in a scrollback; every reply needs an antecedent |
| | Split | Two places to look; every reply means choosing a side |
| | **Adaptive surface** | **Kept.** One column; the conversation lives inside the card it is about |
| Look | A · Ledger | Reads as a spreadsheet. Dense but joyless |
| | B · Marginalia | Beautiful for one email, wrong for thirty-one |
| | C · Slip | The metaphor fights the content; dark ground tires |
| | D · Clean | Correct and anonymous |
| | E · Liquid | The material stole attention from the work |
| | **F · Dock** | **Kept.** Small pieces carry the detail; the work stays the biggest thing on screen |
